## Projects

**[Automation Studio](https://github.com/abhilashyaragal570-del/automation-studio)** (Python, FastAPI, Gemini API, SQLite)
Reads incoming emails with Gemini, picks a category and urgency, extracts the sender, topic and deadline, writes a summary, and drafts a reply. Emails come in through a web page or a secured webhook, go into a job queue that survives restarts, and are handled by a background worker. Includes a login, a dashboard, a jobs log with retry, a daily request cap, search and CSV export.
